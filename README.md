# متجر إلكتروني أندرويد + لوحة تحكم الإدارة (Interactive Mobile Prototype) 📱✨

نموذج تفاعلي سريع ومباشر لتطبيق متجر إلكتروني بنظام أندرويد، يعرض فكرة التطبيق للعملاء والمستثمرين مع محاكاة حية للوحة تحكم الأدمن.

## 🚀 المميزات الرئيسية
* 📱 **تصميم هاتف أندرويد حقيقي ثلاثي الأبعاد:** مع تفاصيل الإطار، الكاميرا المثقوبة، شريط الحالة، وزر الإيماءات.
* ⚡ **العرض المزدوج (Dual-Screen):** مشاهدة متجر العميل ولوحة الأدمن جنباً إلى جنب.
* 🛍️ **تطبيق المتجر:** تصفح المنتجات، تصنيفات، بحث سريع، سلة مشتريات منبثقة، وإتمام الطلب.
* ⚙️ **لوحة تحكم الأدمن:** متابعة المبيعات اللحظية، مراجعة الطلبات الجديدة، وإمكانية إضافة منتجات جديدة تظهر فوراً في المتجر.
* 🔔 **إشعارات فورية وتنبيهات صوتية:** عند إتمام أي طلب من هاتف العميل، يظهر إشعار فوري على هاتف الأدمن.
